# Security Policy

## Supported Versions

We will provide security fixes for the latest version of Pagemate and encourage users through auto-updates to stay current.

## Reporting a Vulnerability

Please file security vulnerabilities via [report a vulnerability](https://github.com/pixelapps-dev/pagemate/security/advisories/new). Please do not file security vulnerabilities as a regular issue — the information could be used to exploit Pagemate users.
